# Research directions

These are starting questions for Zelax Robotics. They describe work we could explore; they are not a release roadmap or a claim that prototypes already exist.

## 1. Contact surfaces

**Starting question:** Can a different covering help a robot hand pick up and release a particular object?

A first study could compare a small set of coverings while keeping the hand, object and task as consistent as possible. Record what changes when the covering changes.

Useful observations:

- Where does the object contact the hand?
- Does the object slip or rotate?
- Does the covering move independently of the finger?
- Does the object release when intended?
- Does the covering restrict the hand's movement?

A fabric-pickup task could be a useful first discussion. A smooth container or a small component would pose different questions. Choose one task before comparing materials.

## 2. Replaceable parts

**Starting question:** Could a worn fingertip or palm section be exchanged without replacing the whole covering?

Possible ideas include a fingertip sleeve, a detachable palm panel or a complete removable cover. Describe how a person would fit, check and replace it.

Useful observations:

- Which areas show wear first?
- How is the part attached, and does it stay in place?
- Can replacement be done with straightforward steps?
- Does the replacement fit consistently?
- How does repeated use or cleaning affect it?

A drawing of the attachment method can be more useful than a polished rendering. Label unfinished details and show where the cover meets the mechanical hand.

## 3. Coverings and sensing

**Starting question:** What information does the task need, and how would a covering work with the sensor?

Possible approaches include leaving an existing sensor exposed, locating a sensor inside a fingertip section, or exchanging an outer contact layer while keeping sensing hardware underneath.

Useful observations:

- What would be measured, and why does the task need it?
- Where would the sensor sit relative to the contact surface?
- Does changing or moving the cover change the reading?
- What needs to stay connected as the hand moves?
- How would the covering be removed or maintained?

Keep measured data separate from imagined behavior. A diagram can explain a proposed signal path without suggesting that it has already been built.

## A small study to begin with

A proposed first comparison: **one hand, one piece of fabric, a few coverings**.

Describe the pickup, hold and release steps. Record the hand and control setup, the material, how the covering is attached, what stays fixed, and what changes. Decide what counts as a successful attempt before collecting results.

Use the [experiment template](experiment-template.md) to make the study understandable to someone who was not there. If there are no results yet, leave the record clearly marked **Proposal**.
